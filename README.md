# idevicerestore-site

Uma landing page simples em HTML/CSS para apresentar o projeto idevicerestore.

## Publicar no GitHub Pages

1. Abra **Settings** no repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.

O site ficará disponível em:

https://enzo-7-farah.github.io/idevicerestore-site/
